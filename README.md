# Foundations of IoT – Laboratory Record Repository

## 1. About
This repository contains the source code, circuit diagrams, and documentation for **IoT Laboratory** experiments. All submissions are organized according to the hardware platform used, maintaining the required documentation and folder structures for every experiment.
